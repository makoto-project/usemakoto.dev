Go recipe

Keep the reference verifier behind an explicit process boundary.

There is no maintained Go SDK. A service can invoke the pinned reference CLI today and replace it only when a native verifier passes the same conformance fixtures.

cmd := exec.Command(
    "uv", "run", "makoto", "verify", "bundle", bundle,
    "--policy", policy,
    "--schema-catalog", catalog,
    "--expected-artifact", expectedArtifact,
    "--evaluation-time", evaluationTime,
    "--json",
)
cmd.Dir = reviewedCoreCheckout
output, runErr := cmd.Output()
if runErr != nil {
    if _, ok := runErr.(*exec.ExitError); !ok {
        return fmt.Errorf("start verifier: %w", runErr)
    }
}

var report VerificationReport
if err := json.Unmarshal(output, &report); err != nil {
    return fmt.Errorf("malformed verifier report: %w", err)
}
if report.Decision != "allow" { return fmt.Errorf("denied: %+v", report) }
if runErr != nil { return fmt.Errorf("verifier failed after ALLOW: %w", runErr) }

Makoto returns a nonzero process status for a well-formed deny decision. Parse and retain that JSON report before handling the process status; a launch failure, malformed report, denial, and inconsistent ALLOW exit are different failures.
