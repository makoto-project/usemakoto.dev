Python recipe

Embed the CLI boundary before depending on internals.

The core repository is implemented in Python, but its internal modules are not yet a stable published SDK. A subprocess keeps your application on the tested command and report contract.

import json
import subprocess

completed = subprocess.run(
    [
        "uv", "run", "makoto", "verify", "bundle", bundle,
        "--policy", policy,
        "--schema-catalog", catalog,
        "--expected-artifact", expected_artifact,
        "--evaluation-time", evaluation_time,
        "--json",
    ],
    cwd=reviewed_core_checkout,
    check=False,
    capture_output=True,
    text=True,
)
report = json.loads(completed.stdout)
if report["decision"] != "allow":
    raise RuntimeError(report)

Pin the core checkout, treat malformed output as failure, and preserve the report’s separate structure, signature, authorization, graph, handoff, freshness, and artifact results.
