Node.js recipe

Invoke the reference report contract.

There is no maintained Node.js verifier package. A server-side process can invoke a pinned core checkout while a native implementation is built against the same fixtures.

import { spawnSync } from "node:child_process";

const result = spawnSync("uv", [
  "run", "makoto", "verify", "bundle", bundle,
  "--policy", policy,
  "--schema-catalog", catalog,
  "--expected-artifact", expectedArtifact,
  "--evaluation-time", evaluationTime,
  "--json",
], { cwd: reviewedCoreCheckout, encoding: "utf8" });

if (!result.stdout) throw new Error(result.stderr);
const report = JSON.parse(result.stdout);
if (report.decision !== "allow") throw new Error(JSON.stringify(report));

Do not send evidence to an undocumented remote service. Keep trust policy and expected artifacts under receiver control.
