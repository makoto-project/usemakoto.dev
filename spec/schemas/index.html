Machine-readable resources

Every hosted schema, with the bytes it is pinned by.

These are the resources a verifier resolves. Each one is served at a stable URL, digested in the catalog, and reproduced below exactly as published, so a reader can compare what a page claims against what the resolver will actually fetch.

Specification overviewNormative textCatalogCurrent release pointer

Each resource has a field reference: every property and definition with its type, whether it is required, its constraints, the rules the specification states for it, and a value read from a real document that validates. The raw catalog.json lists every resource with its digest.

Pin versioned URLs. /schema/latest.json is a convenience pointer to the current catalog for people. It is not an immutable protocol identifier and changes when a new version is published; cite the versioned resource and its digest instead.

Resource index

ResourceWhat it constrains
bundle.schema.jsonThe on-disk bundle layout a sender transfers: statements, attestations, schema closure, and final artifacts. Published bytes
catalog.jsonThe index of hosted resources and their digests. Not a schema itself; the document a resolver pins against. Published bytes
catalog.schema.jsonThe shape of that catalog, so a resolver can validate an index before trusting any entry in it. Published bytes
dataset-manifest.schema.jsonA partitioned dataset described as one subject: member parts, their digests, and the manifest that binds them. Published bytes
envelope.schema.jsonThe DSSE envelope. Signatures authenticate exact payload bytes and nothing about authorization. Published bytes
handoff.schema.jsonThe completeness anchor: roots, heads, statement set, required profiles, final artifacts, and named recipients. Published bytes
origin.schema.jsonThe origin predicate. Source claims, event identity and time, and the exact subjects first observed. Published bytes
profile-dialect.schema.jsonThe restricted JSON Schema dialect a private profile may use, bounded so resolution stays offline and terminating. Published bytes
profile-reference.schema.jsonA profile reference: the schema root URI plus its complete digest-pinned closure. Published bytes
statement.schema.jsonThe common in-toto statement wrapper every Makoto predicate is carried in. Published bytes
transform.schema.jsonThe transformation predicate. Operation metadata, exact predecessors, input artifacts, and output subjects. Published bytes
trust-policy.schema.jsonThe receiver-owned policy: which keys may make which claims, under which thresholds and resource limits. Published bytes
verification-report.schema.jsonThe report contract. Separate outcomes per check, never a single collapsed verdict. Published bytes

The resources

Digests are the catalog's own values. A resolver pins these bytes; it does not trust a live lookup.
