Snowflake with Makoto

Stored procedures + Tasks emit Makoto evidence on every load and transform.

Design note: This is an implementation pattern, not a shipped adapter. The attachment points use real Snowflake APIs; the Makoto calls show where signed evidence would enter the lifecycle.

What is Snowflake?

Snowflake's COPY INTO, Streams, and Tasks framework provides natural attachment points for attestations. Stored procedures can compute content hashes, sign payloads via External Functions, and publish to an attestation table — all in pure SQL.

Streams + TasksPer-batch incremental change capture maps to attestation subjects

Where Makoto attaches

Primary pattern: Stored procedure + Task + External Function for signing. Below are the integration options ordered by lift required.

How Makoto attaches to Snowflake

  • Task or procedure hook — Capture query identity, predecessor statements, and exact exported bytes after a committed transform.
  • Stream-driven task — Bound each claim to a stable table snapshot or exported partition rather than an unbounded relation.
  • External signer — Send an exact in-toto Statement to an operator-controlled signer and persist the returned DSSE envelope.
  • Receiver boundary — Export the envelope graph, signed handoff, and artifact so the consumer can verify them outside Snowflake.

Implementation sketch

Task-driven Transform attestation

Pure SQL — the External Function does the signing

-- 1. Capture base-table changes
CREATE OR REPLACE STREAM sales.mart.orders_changes
  ON TABLE sales.stg.orders;

-- 2. Illustrative operator-owned signing boundary
CREATE OR REPLACE EXTERNAL FUNCTION makoto.sign_statement(payload VARIANT)
  RETURNS VARIANT
  API_INTEGRATION = makoto_signing_api
  AS 'https://signer.example.invalid/makoto'; -- illustrative; operator-owned

-- 3. Task that runs the transform AND emits an attestation
CREATE OR REPLACE TASK sales.mart.refresh_orders
  WAREHOUSE = mart_xs
  SCHEDULE  = '5 MINUTE'
  WHEN SYSTEM$STREAM_HAS_DATA('sales.mart.orders_changes')
AS
BEGIN
  -- Run the transform
  INSERT INTO sales.mart.orders
  SELECT
    order_id,
    sha2(email, 256) AS email_hash,
    total_cents,
    placed_at
  FROM sales.mart.orders_changes;

  -- Emit a signed in-toto Statement. Digests are placeholders:
  -- compute them from stable exported bytes before signing.
  INSERT INTO makoto.attestations
  SELECT makoto.sign_statement(OBJECT_CONSTRUCT(
    '_type', 'https://in-toto.io/Statement/v1',
    'subject', ARRAY_CONSTRUCT(OBJECT_CONSTRUCT(
      'name', 'snowflake://SALES.MART.ORDERS/export.parquet',
      'digest', OBJECT_CONSTRUCT('sha256', '<output-bytes-sha256>')
    )),
    'predicateType', 'https://usemakoto.dev/predicate/v0.2/transform',
    'predicate', OBJECT_CONSTRUCT(
      'schemaVersion', '0.2',
      'event', OBJECT_CONSTRUCT(
        'id', CURRENT_QUERY(),
        'occurredAt', CURRENT_TIMESTAMP()
      ),
      'operation', OBJECT_CONSTRUCT('type', 'snowflake-task'),
      'inputs', ARRAY_CONSTRUCT(OBJECT_CONSTRUCT(
        'name', 'snowflake://SALES.STG.ORDERS/export.parquet',
        'digest', OBJECT_CONSTRUCT('sha256', '<input-bytes-sha256>'),
        'provenance', OBJECT_CONSTRUCT(
          'statementDigest', OBJECT_CONSTRUCT('sha256', '<predecessor-statement-sha256>'),
          'subjectName', 'snowflake://SALES.STG.ORDERS/export.parquet'
        )
      )),
      'extensions', OBJECT_CONSTRUCT('rowCount', SQLROWCOUNT)
    )
  ));
END;

ALTER TASK sales.mart.refresh_orders RESUME;

Where this pattern would matter

Regulated Warehouses

Healthcare, finance, gov — every table mutation leaves a signed receipt.

Data Sharing

Snowflake data shares ship with Makoto evidence the consumer can verify before mounting.

Packaged Distribution

A future Native App could package hooks and storage, but it would still need an external trust policy, signer boundary, tests, and receiver verification.

Time Travel + Makoto evidence

Pair Time Travel snapshots with attestations for full auditable history.

Open implementation

Make the Snowflake attachment point real.
