Integration patterns · no packaged v0.2 adapters claimed

Attach provenance where data changes custody or shape.

Makoto is a protocol boundary, not a replacement for orchestrators, warehouses, stream processors, catalogs, or document tools. An integration creates a signed origin or transformation, preserves predecessor bindings, and carries the resulting evidence into the handoff.

Implementation status: the current repository ships the reference CLI and full local demo. The platform-specific pages linked below are conceptual v0.1 sketches, not maintained or published v0.2 adapter packages.

Four integration responsibilities

1 · Observe

Hash exact bytes

Bind the input or output artifact that the integration actually observed, not a path, table name, or mutable object identifier alone.

2 · Link

Carry predecessors

Reference both the exact input digest and the signed predecessor statement that supplied it.

3 · Attest

Sign one new claim

Create a fresh origin or transformation statement. Do not edit earlier history in place.

4 · Hand off

Give control to the receiver

Transfer the signed bundle while the receiver supplies its own trust policy, schema catalog, expected identity, and final-byte checks.

Common attachment points

PatternUseful momentTypical systems
Lifecycle hookAfter a task materializes an exact outputAirflow, Prefect, Dagster
Operator or asset wrapperAround a transform with explicit inputs and outputsAirflow, Dagster, Databricks
Producer or consumer interceptorAt a message or stream-window custody boundaryKafka and connectors
Macro or post-hookAfter a model or query produces a relationdbt, Snowflake
Catalog listenerWhen a platform publishes a materialization eventSpark, Databricks, catalogs
Write/read boundaryHash on durable write and verify on readObject stores, IO managers, vendor handoffs

Build in the open

An integration becomes real when it has a maintainer, tests, and a verified handoff.

Propose the exact platform surface, artifact boundary, signer identity, failure behavior, and receiver story. The project should not call a code sketch an adapter until those pieces exist.
