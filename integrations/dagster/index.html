Integration field note

Dagster with Makoto

Use asset materialization events to locate exact bytes, predecessor statements, and the right signing boundary.

Design note: This is an implementation pattern, not a shipped adapter. The attachment points use real Dagster APIs; the Makoto calls show where signed evidence would enter the lifecycle.

What is Dagster?

Dagster's asset model records dependencies, partitions, code versions, and materialization metadata. Those events are strong context, but the integration must still hash durable outputs, resolve signed predecessor subjects, and keep authorization policy with the receiver.

Software-defined AssetsAsset graph IS the lineage graph
Materialization MetadataAlready structured — wrap in DSSE envelope
SensorsFire attestation post-materialization without code changes
IO ManagersHash on write, verify on read

Where Makoto attaches

Primary pattern: Asset decorator + sensor + IO manager. Below are the integration options ordered by lift required.

How Makoto attaches to Dagster

  • Materialization sensor — Listen after durable asset writes, then queue evidence generation with the run, asset key, partition, and code-version context.
  • IO manager boundary — Hash the exact serialized artifact on write and preserve the signed predecessor envelope on read.
  • Asset check — Run receiver verification before admitting an external asset; a Dagster success state does not replace trust policy.
  • Job handoff — Assemble only the signed heads and artifacts selected for a downstream recipient instead of merging statements into one mutable run record.

Implementation sketch

Materialization sensor calls a real interface

The sensor resolves the durable object and writes Dagster context as operation metadata before invoking Makoto.

# Triggered after curated_orders/2026-08-24 is materialized.
uv run makoto attest transform \
  --subject "curated_orders.parquet=/assets/curated_orders.parquet" \
  --input-binding /evidence/raw-orders-input.json \
  --operation-type "urn:example:dagster:asset-materialization" \
  --operation-metadata /evidence/dagster-materialization.json \
  --key /run/keys/asset.private.pem \
  --out /evidence/curated-orders.dsse.json

# Persist the envelope beside the artifact or in an evidence store;
# store its digest in Dagster metadata for discovery.
