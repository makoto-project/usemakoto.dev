Technical reference

Licence claim, version 0.3

A signed statement extension that records, for each subject, one SPDX licence expression and one URL where the evidence for it lives.

Protocol version 0.3. Published for review. It is not yet a tagged release, and the current protocol version has no licence claim.

Extension key
https://usemakoto.dev/claim/v0.3/license
Standard profile
license-claim-v1.schema.json
Profile digest
sha256:4b10b1e, 2,115 bytes
Specification
Standard licence-claim profile

The claim

The extension sits in the statement's predicate.extensions. Each claim has exactly subjectName, spdxExpression, and evidenceUrl.

{
  "https://usemakoto.dev/claim/v0.3/license": {
    "claims": [
      {
        "subjectName": "part-00000.parquet",
        "spdxExpression": "CC-BY-4.0",
        "evidenceUrl": "https://example.test/licence-evidence.json"
      }
    ]
  }
}

Rules

  • Claims are sorted by subjectName and cover every statement subject exactly once.
  • spdxExpression is a syntactically valid SPDX 2.x expression. It is parsed without consulting a licence list that can change.
  • evidenceUrl is an absolute HTTPS URL with no fragment.

Requiring it

A receiver requires the claim by adding the standard profile's exact id, digest, closureDigest, and target: "statement" to a trust-policy rule's profileConstraints. The verifier owns the profile bytes and checks their length and digest at startup. A statement without the profile cannot match the rule; one with a missing subject, malformed SPDX, or a bad evidence URL fails with E_PROFILE_INVALID.

The claim identifies the signer that vouched for the declaration. It does not establish that the declaration is true or that the data is legally licensed.
