Case 02 · scientific reproducibility

The chart survived. The method did not.

A paper cites an experiment file, but the source instrument export, outlier rule, normalization parameters, and exact plotting input disappeared when the postdoc left.

Publish the evidence beside the result

  1. Instrument exportStart with exact collected bytes, acquisition time, instrument identity, and the source claim.
  2. Outlier removalAppend an operation statement with predecessor bindings, code identity, parameters, and exact output.
  3. NormalizationAppend the next statement with the statistics and software evidence needed to interpret the claim.
  4. Publication handoffSign the exact graph and final plotting artifact distributed with the paper.

The honest limit

Makoto can preserve the inputs and signed claims needed to reproduce the workflow. It cannot reconstruct missing intermediate bytes after publication or prove that an instrument was calibrated merely because its identifier was signed.

Make the next paper inspectable

Start the graph when data leaves the instrument, not when the PDF is submitted.
