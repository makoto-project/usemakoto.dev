    Where every value comes from

    Nothing on this page is typed in. The data files, the signed statements, the handoff manifest, and the verification reports are loaded from the end-to-end proof's published artifacts, and the digest of each data file is computed in your browser from the bytes it loaded. The verified properties are computed from each report with core's own rules. The attacks are the proof's seven denial cases, each explained in the casebook.

    To see the track levels and properties behind each stage in full, read the assurance model. To run the same proof yourself, follow the end-to-end walkthrough.
