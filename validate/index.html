Structural validation

JSON Schema answers “is this shaped correctly?” Nothing more.

Makoto publishes ordinary Draft 2020-12 schemas with CORS enabled. Use them in editors, CI, and ingestion gates. Then use the reference verifier for signed payload bytes, signer authorization, profiles, graph continuity, handoff completeness, freshness, and the data bytes received.

LayerChecksDoes not check
Core schemaEnvelope, statement, predicate, profile reference, handoff, policy, bundle, and report shapes.Signatures or cross-resource meaning.
Organizational profileDeclared metadata or supported structured-artifact constraints.Whether the signer is authorized or the source is truthful.
Reference verifierStructure plus cryptography, authorization, graph, handoff, freshness, and artifacts.Data quality, confidentiality, compliance, or execution truth.

Runnable command-line check

uvx --from check-jsonschema check-jsonschema \
  --schemafile https://usemakoto.dev/schema/v0.2/trust-policy.schema.json \
  policy.json

Replace the schema URL with the resource type you are validating. The hosted catalog lists every core schema and SHA-256 digest.

Python with jsonschema

import json
from urllib.request import urlopen
from jsonschema import Draft202012Validator

with urlopen("https://usemakoto.dev/schema/v0.2/trust-policy.schema.json") as response:
    schema = json.load(response)
with open("policy.json", encoding="utf-8") as source:
    instance = json.load(source)

Draft202012Validator.check_schema(schema)
Draft202012Validator(schema).validate(instance)

This is structural validation. It deliberately does not reproduce strict JSON parsing, digest-pinned profile closure, or bundle-verification ordering from the reference implementation.

Node.js with AJV

import Ajv2020 from "ajv/dist/2020.js";
import policy from "./policy.json" with { type: "json" };

const schema = await fetch(
  "https://usemakoto.dev/schema/v0.2/trust-policy.schema.json"
).then((response) => response.json());

const validate = new Ajv2020({ strict: true }).compile(schema);
if (!validate(policy)) throw new Error(JSON.stringify(validate.errors));

Pin the schema bytes or catalog digest in controlled builds rather than treating a mutable network response as a trust root.

CI boundary

# Structure only
uvx --from check-jsonschema check-jsonschema \
  --schemafile https://usemakoto.dev/schema/v0.2/envelope.schema.json \
  evidence.dsse.json

# Complete receiver decision from a reviewed core checkout
uv run makoto verify bundle --help

Implement the check your runtime actually needs.

Keep schema validation visibly separate from complete verification, and contribute cross-language fixtures when two implementations should agree.
