v0.2 candidate tooling · package publication pending

Use what exists. See exactly what does not.

Makoto has a tested reference CLI and library in the core source tree, hosted candidate schemas, and a cloneable demo. The earlier Python and JavaScript SDK directories remain useful experiments, but they are v0.1 and are not published v0.2 packages.

SurfaceStatusUse it for
Reference CLI and Python libraryCurrent v0.2 sourceCreate, sign, bundle, and verify candidate evidence from a cloned checkout.
Hosted JSON SchemasPublic candidate URLsValidate core resources and resolve candidate protocol schemas.
End-to-end demoRunnable and testedExercise the full source, transform, handoff, and receiver verification story.
Python and JavaScript SDK directoriesHistorical v0.1 experimentsStudy earlier API ideas only; do not treat them as v0.2-compatible packages.
Platform adaptersConceptual sketchesExplore attachment points; no maintained v0.2 adapter packages are claimed.

Run the current reference implementation

git clone https://github.com/makoto-project/makoto.git
cd makoto
uv sync --locked --dev
uv run makoto --help
./scripts/demo-v0.2.sh --acceptance

This is a source checkout, not an install command for a released package. The demo is the shortest verified path through the current implementation.
